### What I learned

One of the main things I learned from this project was how to use `clamp()` for responsive typography.

At first, I was using fixed font sizes, but I wanted the typography to adapt better to different screen sizes. By working with `clamp()`, I learned how to set a minimum, preferred, and maximum font size without needing multiple media queries.

I also practiced using self-hosted fonts and preloading the font with `<link rel="preload">`.

Another thing I learned was how to create and style different interactive states, such as `:hover` and `:active`, and use CSS transitions to make them feel smoother.

I want to continue improving my CSS skills, especially responsive design, Flexbox, typography, and accessibility.
